# Bug check, 2026-11-03

Scope: CLI wrapper and Python runner review, with targeted CLI reproductions against the existing build. This is not an exhaustive native allocator, GPU, or browser audit. No product code changed. Three confirmed bugs.

## 1. High: reusing an output directory includes previous runs

Location: `heaptide:97`.

Reproduce:
```sh
./heaptide run --out .work/bug-audit/reuse -- ./build/c_leak
./heaptide run --out .work/bug-audit/reuse -- /usr/bin/true
./heaptide report .work/bug-audit/reuse --json
```

Observed: the report still includes the earlier `c_leak` process and its 100005 direct leaked bytes. Run initialization removes only `root`, leaving earlier reports. Reporting that directory mixes distinct runs, corrupting leak verdicts and comparisons.

Suggested fix: isolate each run in a fresh directory, or reject an output directory containing existing profiling artifacts. Preserve unrelated user files. Explicitly support aggregation separately if needed.

Evidence: `.work/bug-audit/reuse.log`, `.work/bug-audit/reuse.json`.

## 2. Medium: Python interpreter options become script filenames

Location: `heaptide:103`, `py/run.py:173-175`.

Reproduce:
```sh
./heaptide run --py --out .work/bug-audit/pyflag -- python3 -u -c 'print("TARGET_OK")'
```

Observed: `FileNotFoundError` for `<repo>/-u`; target never executes. The wrapper inserts the runner before all interpreter arguments, and the runner only recognizes an initial `-c` or `-m`.

Suggested fix: parse supported interpreter options and place them before the runner; preserve script/module/code arguments after it. Reject unsupported interpreter modes with a clear usage error rather than treating flags as paths.

Evidence: `.work/bug-audit/pyflag.log`.

## 3. Medium: incomplete diff failure policy silently succeeds

Location: `report/heaptide_report.mojo:745-756`.

Reproduce:
```sh
./heaptide diff .work/bug-audit/reuse .work/bug-audit/reuse --fail-on
```

Observed: exit 0 without a usage error. The argument loop only updates the policy when processing an argument following `--fail-on`, so a trailing flag silently keeps the default. Unknown options are also ignored by this loop. Automation can run with a different policy than requested.

Suggested fix: use explicit option/value parsing for diff, require a value after `--fail-on`, and reject unknown options. Return status 2 for malformed input.

Evidence: `.work/bug-audit/diff-invalid.log` (empty); reproduction returned status 0.

All three fixed 2026-11-03: f895cd6 (reuse), d5a5967 (interpreter options), 35a9670 (diff options). Regression checks `c_reuse`, `py_opts`, `diff bad_args` fail on the old wrapper and pass now (CPU suite 233/233).
